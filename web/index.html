KeyStep Pro Mods

New tricks for your KeyStep Pro. Pick the mods you want, drop in the official firmware file, and flash the result with MIDI Control Center like any update. Everything happens in this browser. The guide explains every mod, flashing, and going back.

Flashing the official update puts the original firmware back.

What changed

The file you build is named after the version, for example , so you can see which one is on your KeyStep. If yours is older than the newest version below, build and flash it again.

Flash the downloaded file with MIDI Control Center. To go back, flash the original update file. The mods work on firmware 2.5.20, on the KeyStep Pro and the KeyStep Pro Chroma; your firmware file never leaves this browser. Step by step: flashing, going back and if it does not start.
